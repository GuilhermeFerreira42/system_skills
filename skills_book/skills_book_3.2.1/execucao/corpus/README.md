# Corpus da execução

Coloque aqui as fontes brutas. Preserve os originais.

O Orquestrador pode criar um mapa de módulos para carregar apenas o material relevante em cada capítulo. O mapa otimiza contexto; não altera nem resume a fonte original.

**Importante:** Este é um espaço para trabalhar com seus próprios materiais. NÃO inclua conteúdo protegido por direitos autorais sem permissão.

**Dica:** Organize seu corpus em subpastas temáticas para facilitar a navegação e a criação do mapa de módulos.

Material de marketing deve ser identificado e excluído do livro conforme a Lei 6.
