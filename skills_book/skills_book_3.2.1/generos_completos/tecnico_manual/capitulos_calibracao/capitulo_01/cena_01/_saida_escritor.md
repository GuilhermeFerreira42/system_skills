## O que é Python

Python é uma linguagem de programação criada por Guido van Rossum e lançada pela primeira vez em 1991. Ela é chamada de linguagem de "alto nível" porque a sintaxe se aproxima da linguagem humana, em vez de se aproximar da linguagem da máquina (que é binária).

A principal característica do Python é a legibilidade. O código Python é projetado para ser lido por humanos, não só por computadores. Isso significa que, uma vez que você aprende o básico, consegue ler o código de outras pessoas com relativa facilidade. Compare isso com linguagens como C ou Assembly, onde a sintaxe é mais complexa e mais distante da leitura humana.

## Para que Python é usado

Python é uma linguagem de propósito geral. Isso significa que ela não é feita para um único domínio, mas pode ser usada em muitos:

- **Desenvolvimento web** (com frameworks como Django e Flask)
- **Ciência de dados** (com bibliotecas como pandas, NumPy, scikit-learn)
- **Automação de tarefas** (scripts para processar arquivos, fazer web scraping, enviar emails)
- **Inteligência artificial** (com TensorFlow, PyTorch)
- **Desenvolvimento de jogos** (com Pygame)
- **Aplicações desktop** (com Tkinter, PyQt)

Você não precisa decidir agora em qual área vai trabalhar. A graça de Python é que, uma vez que você aprende o básico, consegue migrar entre áreas sem reaprender do zero.

## Por que Python é uma boa escolha para iniciantes

Existem muitas linguagens de programação. Por que escolher Python como primeira?

Primeiro, a sintaxe é simples. Em muitas linguagens, você precisa escrever vários símbolos para fazer uma coisa simples. Em Python, a sintaxe é mínima. Por exemplo, para imprimir uma mensagem na tela:

```python
print("Olá, mundo!")
```

Essa é a primeira linha de código que você vai escrever. Uma linha. Sem símbolos extras, sem configuração prévia.

Segundo, a comunidade é enorme. Python está entre as linguagens mais usadas no mundo, e a comunidade é conhecida por ser acolhedora com iniciantes. Se você tiver uma dúvida, é muito provável que alguém já tenha feito a mesma pergunta e alguém já tenha respondido.

Terceiro, a demanda no mercado é alta. Aprender Python abre portas em diversas áreas profissionais. Não é garantia de emprego, mas é uma habilidade valorizada.

## O que esperar deste manual

Este manual é sequencial. Cada capítulo constrói sobre o anterior. Você não vai aprender tudo de uma vez, e isso é proposital. Programação é uma habilidade que se constrói com prática, não com leitura passiva.
