# podbook_mentor — Perfil de Gênero Completo

**Versão:** 1.0
**Aplicação:** este é o perfil de gênero para livros baseados em transcrições de aulas, com voz de mentor experiente, formato "módulo de áudio".

---

## Quando usar este gênero

Use este perfil quando:
- O livro é baseado em transcrições de aulas reais (cursos online, palestras, mentorias)
- O conteúdo é didático, não ficção
- O narrador é um especialista/mentor contando sua experiência
- O público quer um livro que também funciona como audiobook/podcast
- O método tem etapas claras (Planejamento → Estrutura → Audiência → Vendas → Atendimento → Impulsão, ou similar)

**Exemplos de livros que se encaixam:**
- Ecommerce do Zero (Bruno de Oliveira)
- Investimentos para Iniciantes (qualquer mentor de finanças)
- Marketing Digital do Zero (qualquer especialista)
- Programação para Iniciantes (qualquer dev sênior ensinando)
- Saúde e Bem-Estar (qualquer profissional contando casos)

---

## O que tem aqui

- `GENERO.md` — Arquivo principal do gênero (preenchido)
- `BIBLE_EXEMPLO.md` — Bible exemplo com Ecommerce do Zero
- `capitulos_calibracao/capitulo_01/` — Cap 1 completo, 3 cenas, prosa + resultados de validação

---

## Como usar

1. Copie `GENERO.md` para `execucao/GENERO.md` do seu projeto
2. Use `BIBLE_EXEMPLO.md` como referência de estrutura para criar a Bible do SEU livro
3. Olhe `capitulos_calibracao/capitulo_01/` para calibrar tom, formato e granularidade
4. Configure o `CONFIG.md` com título, corpus, foco
5. Passe para a IA produtora

---

## Calibração disponível

O `capitulos_calibracao/capitulo_01/` contém o **Capítulo 1 completo do Ecommerce do Zero** (3 cenas), usado como referência de calibração de tom, formato, e granularidade. Serve para a IA produtora entender exatamente como o pipeline funciona nesse gênero.
