# Nivelamento editorial da Skill 3

O nivelamento é uma calibração humana curta para construir o contrato de voz da obra. Ele substitui a dependência de templates de gênero carregados no boot.

As respostas não são métricas nem metas de produção. Elas são vetores qualitativos:

- como abrir;
- quão profundamente explicar;
- quando usar analogias e exemplos;
- como o narrador se posiciona.

O resultado é salvo em `Bible > Perfil Editorial` e espelhado no Estado.
