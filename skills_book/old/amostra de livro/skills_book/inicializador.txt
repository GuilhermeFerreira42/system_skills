# INICIALIZADOR DO SISTEMA DE ESCRITA DE LIVRO

**Versao:** 1.0
**Data:** 2026-07-27

---

## Como Iniciar

1. O usuario fornece:
   - Caminho do corpus (livro fonte, notas, transcrições, pesquisa)
   - Genero desejado (arquivo em `generos/GENERO_*.md`)
   - Foco do usuario (instrução livre sobre o que priorizar)

2. O Orquestrador:
   - Le o corpus completo
   - Carrega o genero em runtime
   - Cria/le a Bible da Obra (`bible/bible_da_obra.md`)
   - Cria/le o Estado da Obra (`estado/estado_da_obra.md`)
   - Gera o Plano de Capítulos baseado no genero + corpus + foco
   - Inicia o loop de produção capítulo a capítulo

## Estrutura de Pastas do Projeto

```
projeto_livro/
├── corpus/                    # Material bruto fornecido pelo usuario
│   └── corpus_original.md
├── bible/                     # Bible da obra (fonte da verdade)
│   └── bible_da_obra.md
├── estado/                    # Estado granular da produção
│   └── estado_da_obra.md
├── capitulos/                 # Cada capítulo = worktree isolado
│   ├── capitulo_01/
│   │   ├── _saida_escritor.md
│   │   ├── _afirmacoes_para_validar.json
│   │   ├── _resultado_march.json
│   │   ├── _resultado_continuidade.json
│   │   ├── _saida_editor.md (opcional)
│   │   └── rascunhos/
│   └── capitulo_NN/
├── generos/                   # Carregados em runtime pelo orquestrador
│   ├── GENERO_ROMANCE.md
│   ├── GENERO_NAO_FICCAO.md
│   ├── GENERO_MEMORIAS.md
│   ├── GENERO_TECNICO.md
│   └── GENERO_PERSONALIZADO.md (criado ad-hoc)
├── livro_final.md             # Output consolidado
└── livro_final.epub           # Output final (opcional, gerado pelo consolidador)
```

## Arquivos Principais do Sistema

| Arquivo | Funcao |
|---------|--------|
| `orquestrador/BOOT_ORQUESTRADOR_LIVRO.md` | Inicialização do orquestrador |
| `orquestrador/SKILL_ORQUESTRADOR_LIVRO.md` | Pseudocódigo obrigatório do fluxo |
| `escritor/BOOT_ESCRITOR_CAPITULO.md` | Inicialização do escritor de capítulos |
| `escritor/SKILL_ESCRITOR_CAPITULO.md` | Regras de escrita narrativa |
| `atomizador/SKILL_ATOMIZADOR.md` | Extração de afirmações factuais (reaproveitado) |
| `validador_march/SKILL_VALIDADOR_MARCH.md` | Fact-check cego (reaproveitado) |
| `validador_continuidade/SKILL_VALIDADOR_CONTINUIDADE.md` | **NOVO** - Continuidade cega (Bible + estado) |
| `editor/SKILL_EDITOR.md` | **OPCIONAL** - Voice consistency, pacing, show-don't-tell |
| `consolidador/SKILL_CONSOLIDADOR.md` | Junta capítulos → livro final |
| `controle_da_obra/SKILL_CONTROLE_DA_OBRA.md` | **NOVO** - Espelho do filesystem, fonte de verdade de progresso |
| `revisor_cego_editorial/SKILL_REVISOR_CEGO_EDITORIAL.md` | **NOVO** - Checker cego de forma editorial (estrutura, clareza, ritmo) |
| `generos/GENERO_*.md` | Definem estrutura, voz, POV, pacing por gênero |
| `bible/TEMPLATE_BIBLE.md` | Template da Bible da Obra |
| `estado/TEMPLATE_ESTADO.md` | Template do Estado da Obra |
| `esquema/ESTRUTURA_PROJETO_LIVRO.md` | Este arquivo (referência estrutural) |
| `exemplos/FLUXO_COMPLETO_LIVRO.md` | Exemplo end-to-end |

## Ordem de Execução Obrigatória

```
ORQUESTRADOR
  ├─> ESCRITOR (escreve capítulo)
  ├─> ATOMIZADOR (extrai afirmações factuais)
  ├─> VALIDADOR_MARCH (fact-check cego vs corpus)
  ├─> VALIDADOR_CONTINUIDADE (continuidade cega vs Bible + estado anterior)
  ├─> EDITOR (opcional, se genero.exige_editor)
  └─> ATUALIZA Bible + Estado
      ↓ (loop próximo capítulo)
CONSOLIDADOR (junta tudo → livro_final.md)
```

**REGRA DE OURO:** Nenhum capítulo é CONCLUIDO sem:
1. `_resultado_march.json` com status "APROVADO"
2. `_resultado_continuidade.json` com status "APROVADO"
3. Bible e Estado atualizados atomicamente
