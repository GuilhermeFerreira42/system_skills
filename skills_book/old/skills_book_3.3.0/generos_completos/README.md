# Perfis de gênero — referências opcionais

Os perfis desta pasta são exemplos e material de calibração herdado da base Skill 1. Eles não são carregados automaticamente no boot da Skill 3.

O Orquestrador usa primeiro o nivelamento editorial e o foco do usuário. Um perfil pode ser consultado quando o usuário pedir uma referência de domínio, mas suas regras devem ser traduzidas em orientação qualitativa antes de chegar ao Escritor.

## Regra

Nenhum perfil desta pasta pode impor ao Escritor:

- contagem de palavras;
- porcentagem de parágrafos;
- média de frases;
- desvio-padrão;
- proibição estatística de ritmo.

Quando um perfil antigo contiver esse tipo de instrução, ela é histórica e não faz parte do contrato Skill 3.
